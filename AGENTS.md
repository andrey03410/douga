# Douga — вход для агентов

**Douga** (動画, «видео») — личный генератор аниме-видео владельца: видео-топы,
пикеры («выбери персонажа»), турниры сравнений, импорт из Shikimori и YouTube,
AI-студия на SDK, которой управляет внешний ИИ через MCP. Правки вносит только
владелец, поэтому процесс лёгкий.

Этот файл одинаково читают Claude Code (через `CLAUDE.md`), Codex и Cursor.

## Стек и команды

Next.js 14 (App Router) · React 18 · TypeScript · Prisma 5 + SQLite · Auth.js ·
Remotion 4 · ffmpeg-static · Zod · Vitest · Node 22.

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт на :3000. Сначала проверь порт, см. [dev-env](.ai/map/dev-env.md) |
| `npm run studio:worker` | очередь студии SDK, отдельный процесс |
| `npm run mcp` | MCP-сервер `douga` (stdio) |
| `npm test` → `npm run build` → `npx tsc --noEmit` | обязательная тройка проверок, именно в этом порядке |

Запуск и переменные окружения описаны в [`README.md`](README.md).

## Как ведём задачи

Каждая задача идёт по стадиям скилла [`feature`](.claude/skills/feature/SKILL.md):
бриф → продукт (если нужен) → техника → план → реализация и QG → проверка
владельцем → вливание через PR. У задачи своя папка `.ai/features/NN-slug/`,
её статус записан во frontmatter `README.md`. Гейты — явные ответы владельца
(«продукт ок», «техника ок», «принято»). После плана гейта нет.
**Без «принято» не вливать.**

## Скиллы

Скиллы лежат в `.claude/skills/`. `.agents/skills` — симлинк на эту папку для Codex,
Cursor читает обе. Если владелец назвал скилл или запрос совпал с его триггером,
прочти `SKILL.md` целиком и выполни. В Codex скилл вызывается как `$имя`, в Claude Code и Cursor — `/имя`.

| Скилл | Для чего | Когда |
|---|---|---|
| [`feature`](.claude/skills/feature/SKILL.md) | стадии задачи | новый бриф, «статус», «продукт ок», «принято» |
| [`verify`](.claude/skills/verify/SKILL.md) | QG и живая проверка | стадия QG, перед PR, «проверь» |

Плагин superpowers, если он есть, можно использовать внутри стадий. Но его
артефакты кладутся в папку задачи, а не в `docs/superpowers/`.

## Правила

- Доки и общение — по-русски. Код, идентификаторы и коммиты — по-английски, в conventional-стиле: `feat(studio): …`.
- ИИ-материалы хранятся только в `.ai/` и здесь. Новый тип материалов — новая подпапка и строка в [`.ai/README.md`](.ai/README.md).
- Поменял поведение зоны — поправь её карточку в той же ветке. Спеки и планы фаз — архив, их не переписываем.
- Готовность не объявляется по типам и юнитам. Обязательно: тройка после последних
  правок, плюс проверка на живой поверхности по затронутым зонам (сайт, настоящий MCP,
  реальные кадры, декодированный звук). Как именно — в скилле `verify`. Для правок
  только в доках тройку не гоняют, достаточно проверить ссылки.
- Репозиторий публичный. `.env` и `storage/` в `.gitignore`. Пароли и токены не печатать
  и не коммитить. Проверочные аккаунты и данные держать в `storage/`.
  Чужие проекты и медиа владельца ради проверок не менять.
- Финальный рендер доступен только админу. MCP действует от лица `MCP_ACTOR_EMAIL`
  зарегистрированного аккаунта, а сервисы заново проверяют права, владение и квоты.
- SDK не исполняет произвольный JS/TSX из документа. Новый эффект добавляется
  расширением версионированной схемы, компилятора и рендерера. Классические
  конструкторы живут отдельно, их лимиты (9 карточек, 50 раундов) в SDK не переносить.
