# .ai — знания проекта

Вход для агента — [`AGENTS.md`](../AGENTS.md) в корне. Здесь то, на что он ссылается.

| Папка / файл | Что там | Живое или архив |
|---|---|---|
| [`map/`](map/) | Карточки зон кода: где лежит, как устроено, грабли, как проверить | живое — правится вместе с кодом |
| [`features/`](features/) | Задачи с 22-й: папка на задачу, файл на стадию | живое, пока задача не влита |
| [`history.md`](history.md) | Строка на каждую фазу/фичу со ссылками | дописывается при вливании |
| [`specs/`](specs/) | Спеки фаз 1–21; контракты SDK 22–25 ещё актуальны | архив (кроме контрактов) |
| [`phases/`](phases/) | Планы и журналы приёмки фаз 1–21 | архив |
| [`research/`](research/) | Исследования и сравнения подходов | по ситуации |
| `production/` | Рабочие папки реальных роликов (в `.gitignore`) | локально |

Правила:
- Карточка `map/` описывает код **сейчас**. Поменял поведение зоны — поправь её карточку в той же ветке.
- Архив не переписываем: если решение устарело, актуальное пишется в карточку.
- Новый тип материалов — новая подпапка и строка в этой таблице.
