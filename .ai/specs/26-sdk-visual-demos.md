# Три демонстрации SDK — 2026-10-27

Пользователь поручил создать три коротких красивых и разных видео, сразу устраняя обнаруженные ограничения SDK. Работа продолжается в `codex/ai-video-sdk`, исходный код этого продолжения — a64e98b. Прежние проекты не меняются.

1. Семья: Минато, Кушина и Наруто. Поочерёдное плавное появление, имена над карточками, ребёнок меньше между родителями, стрелки от обоих родителей. Тёмное зелёное оформление с золотом, 16:9, около8с.
2. Арена: три группы по8 реальных персонажей Naruto/Bleach/OnePiece. Только аватарки внутри групп, два VS между группами. Неоновое оформление, последовательный вход групп и каскад аватарок, 16:9, около8с.
3. Два аниме: трактовка исполнителя — два блока рядом, в каждом большой постер и три соответствующих персонажа под ним. Общего названия раунда нет. Светлая журнальная композиция, 1:1, около8с.

Постеры получаются через существующий Shikimori MCP и сохраняются в личном пуле. Музыка/эффекты — собственные короткие синтезированные ассеты. Все проекты создаются через публичный MCP, рендерятся общей очередью/worker и остаются доступны на сайте.

Обнаруженное ограничение: строгая схема позволяет только однотонные цвета. Добавляем `CardStyle.gradient` (linear/radial, нормализованные stops, без URL/произвольного CSS) и `CardStyle.shadow` (цвет, x/y/blur/spread с конечными ограничениями). Градиент рисуется поверх solid background. Отсутствие полей сохраняет прежний вид, параметры проходят компилятор и media-free preset roundtrip; Player и offline используют один рендерер. Никаких новых зависимостей/миграций.

Проверка: RED→GREEN схемы/компилятора/пресета, настоящий PNG с проверкой градиента и тени, три финальных MP4 с просмотром нескольких стадий появления и звука, живой сайт, полный npm test/tsc/build и одно независимое ревью нового изменения.

Обнаруженная ошибка при настоящем MCP-осмотре: `-ss 0` перед единственным JPEG-кадром может завершить ffmpeg без байтов. Для Art.kind=image перемотка не нужна и исключается, а fromSec!=0 по-прежнему отклоняется. Реальный JPEG→MCP image/resource→PNG RGB тест должен воспроизвести RED и закрыть исправление.
