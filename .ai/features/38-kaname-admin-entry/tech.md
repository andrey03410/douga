# Технические решения

T01. Страница /admin вызывала currentUser, который превращает и отсутствие сеанса, и запрет на доступ в null. Страница всегда возвращала 404. Для решения о начале OIDC использовать причину отказа requireUser: только UNAUTHENTICATED ведёт к входу, FORBIDDEN ведёт к 404.

T02. У обработчика начала входа уже есть штатные Auth.js-проверки state, nonce и PKCE. Его параметр next может выбрать только известный путь /admin; во всех остальных случаях сохраняется /projects.
