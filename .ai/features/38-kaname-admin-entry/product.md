# Продуктовые решения

P01. Отсутствие локальной сессии при переходе в админку запускает привычный вход в Keycloak. После успеха владелец попадает прямо в управление Douga.

P02. При действующей сессии участника админка возвращает 404. После отзыва назначения повторный вход с той же сессией автоматически не запускается. Самостоятельный режим Douga сохраняет исходное поведение.
