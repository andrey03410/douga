# Технические решения

Существующие Auth.js Credentials и JWT ведут к локальному User. HTTP MCP разрешает персональный токен, stdio хранит актора процесса. Studio проверяет владение в shared. SQLite и Prisma хранят проекты, ревизии, отдельные таблицы линейных и интерактивных публикаций и очередь. Исходники и производные файлы лежат в storage.

T01. Только проверенная пара issuer/subject связывается с локальным аккаунтом. Сессия Keycloak имеет локальную запись. Полномочия получаются напрямую из Kaname заново. Сессии, персональные токены и воркеры ограничивает локальная приостановка.

T02. Матрица получает отдельные имена для централизованных ролей. Модерация не выдаёт роли. Вход и создание аккаунта по паролю доступны в автономном режиме.

T03. Лимиты числа ресурсов проверяются в записывающей транзакции. Проверка дисковой квоты учитывает оригиналы и производные материалы одного владельца. Обе разновидности публичной ссылки входят в общий лимит.

T04. Активность хранится по дням UTC. Отчёт требует отдельный входящий ключ, не влияет на активность и видит только локальные данные.
