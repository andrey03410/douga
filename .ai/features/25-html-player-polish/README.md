## Хвосты

- Номер 25 занят этой задачей. Удаление классических конструкторов
  ([P14 задачи 24](../24-html-player/product.md#p14-удаление-классических-конструкторов))
  получит следующий свободный номер.
- Ссылка `/watch` отдаёт исходные файлы целиком. Окна нарезки есть только у `.html`.
  Для ролика из отрывков длинных треков страница качает больше, чем нужно.
- Окно видео-узла тянется до `freezeAtFrame`, а это обычно конец источника. Поэтому
  видео чаще встраивается целиком, чем режется. Окно консервативное, точнее можно,
  если учитывать, где кадр замирает.
- Обёрток над ffmpeg теперь несколько (`export-slice.ts`, рендер, импорт). Объединить
  их стоит отдельной задачей.
- Блокировку публикации между процессами автотест не ловит. Внутри одного процесса
  Prisma и так ставит транзакции в очередь (см. [tech.md](tech.md#t10-публикация-и-http)).
  Нужен тест на два процесса.
- `WatchShell` лежит в клиентском модуле плеера, поэтому страница «Ролик снят
  с публикации» тоже тянет бандл Remotion.
- На `If-None-Match` медиа `/watch` не отвечают 304. При `immutable` браузер и так
  не переспрашивает.
- На первом ▶ звук первой реплики перематывается с кадра обложки на 0 и даёт одно
  событие `waiting` на 0,0 с. Это до старта картинки, в ходе просмотра таких событий нет.
