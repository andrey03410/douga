# Досрочное изменение прав зарегистрированных

## Основание и границы

2026-11-17 владелец прямо поручил: «Давай вообще уберем для простоты обычного юзера,
пока сделай так что любой зарегестрированный будет иметь права админа».
Изменение реализуется сейчас как отдельно разрешённый пункт P11. Это не означает
разрешение реализовать остальную визуальную фичу или влить ветку.

## Решение

- Новая регистрация явно сохраняет admin.
- Старая роль user читается как совместимый псевдоним admin в единой матрице.
  Существующие сессии, MCP и worker получают те же права без массовой миграции.
- Доступны финальный MP4, админка, пул и число турниров без прежних квот user.
  Технические бюджеты и существующий admin-предел архива сохраняются.
- Убрать выбор обычного user в админке; совместимый API принимает назначение admin.
- Гость/неизвестная роль остаются без прав. Принадлежность проекта проверяется
  независимо от административных прав.
