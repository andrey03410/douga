# 26. Удаление классических конструкторов — видео только через SDK и агента

Удаляем прежние «Мои видео» целиком: ручной и турнирный топ, пикер, их страницы, API,
MCP-инструменты, композиции Remotion, модели вместе с данными и старые MP4.
Остаются турниры (источник рейтинга), пул медиа и AI Video SDK. Видео собирает агент
через MCP `video_*`, топ по турниру и свой топ — тоже.

**Автономный режим:** продукт и техника решены агентом. Реализацию, QG и PR владелец
поручил сделать без него и без вливания — гейт «принято» остаётся. Слова — в
[brief.md](brief.md#автономный-режим).
