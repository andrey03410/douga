## Ревью

Первый просмотр делал исполнитель (Codex) по ходу реализации: существенных дефектов не нашёл.

Свежее ревью ветки, 2026-11-02, агент вливания (Claude). Существенное исправлено в той же ветке:

| Находка | Исправление |
|---|---|
| Рецепт топа по турниру в инструкции MCP вёл в ошибку: `video_project_create` не принимает `sourceId` без `presetId` («Factory options require presetId»). Живой прогон Codex сам шёл через `presetId: "top.classic.wide"` | Инструкция, README, карточка `mcp.md` и скилл `verify` называют пару `presetId` + `sourceId`. Тест `instructions.test.ts` держит это и проверяет, что пресет из примера существует (`75f9547`) |
| `roles.integration` и `account.integration` писали файлы в `storage/renders/`, и каждый прогон тестов заново создавал удалённый каталог. После QG Codex он снова лежал в `storage/` | Тесты больше не трогают `renders/`, пустой каталог удалён (`0f9f421`) |
| Из `mcp.e2e` вместе с классикой ушли проверки, которые классики не касаются: `USER_NOT_FOUND`, счётчики списка Shikimori, тип и подпись импортированного файла, путь в `list_pool` | Проверки возвращены (`0f9f421`) |
| `MediaBrowser` сохранил режим выбора для удалённой модалки (`onPick`, `pickKinds`, `header`, `manage`, сетка), в `globals.css` остались стили модалки, кропа, плиток и карточек проектов — 283 строки | Остался вид строк кабинета. Мёртвых классов в CSS нет. Отступ `.group-grid` турнира, который давал старый блок пикера, перенесён в правило фазы 18 (`60b7e0e`) |
| README и скилл `verify` описывали удалённое: «Конструктор рендера», менеджер рендеров в кабинете, тесты плана видео и пикера, рецепты модалки и кропа, разделы фаз 7 и 16. В `media.md` — команда с удалённым `art-crop.test.ts` | Переписано под SDK и импорт в кабинете (`9d3cf81`, `60b7e0e`) |

Не исправлял:

- `tsconfig.json` исключает `storage/`. Это правка Codex: в `storage/` лежит его драйвер `26-setup.mts`. Исключение верное и без него: `storage/` — данные, а не код.
- `video_source_list` отдаёт турниры постранично, строкой не фильтрует. Агент находит турнир по названию в списке. Параметр поиска — новая функция, не удаление.
- Вставка `Ctrl+V` теперь ловится на всей странице кабинета, а не только в модалке. Так задумано P07: вставка в поле ввода по-прежнему игнорируется.
