# План

**Цель:** убрать классические конструкторы целиком и оставить SDK единственным путём к видео.

**Подход:** сначала вынести куски, которые нужны студии и офлайн-плееру, затем убрать вызовы классики из живого кода и удалить её файлы. Схему и данные трогаем последними, когда код на модели больше не ссылается. Каждый коммит проходит `npx tsc --noEmit`. Новое поведение пишется через красный тест. Решения — [tech.md](tech.md), продукт — [product.md](product.md).

Владелец в этой сессии разрешил реализовать задачу автономно и открыть PR, без вливания. Слова — в [brief.md](brief.md).
