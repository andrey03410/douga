# Проверка Douga

- Рабочая сборка Next.js и проверка типов прошли. На первой полной локальной проверке прошли 1711 тестов. Проверка завершения дочернего процесса yt-dlp получила `EPERM` на macOS, после чего прошла изолированно и повторно в наборе импорта.
- 20 целевых тестов проверили роли и публикацию интерактивного снимка без воркера. При неизменном исходном поведении новый тест сначала получал `preparing`, после исправления получил готовый манифест и ноль заданий на генерацию кадров.
- GitHub Actions собрал Linux-образ и запустил Next.js с временной SQLite в [проверке PR](https://github.com/andrey03410/douga/actions/runs/44733653616).
- Независимое ревью проверило роли, закрытую регистрацию и серверный сценарий выпуска. Публичный адрес и рабочие учётные записи проверяются после деплоя merge-коммита.
