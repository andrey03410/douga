# Доступ на бою

Владелец и друзья входят в предварительно созданные аккаунты. Регистрация через сайт и гостевые приглашения выключены в серверном образе. Локальная разработка сохраняет прежний режим входа.

- **P01.** Для `andrey` используется роль администратора, где она есть. Остальные аккаунты получают роль обычного пользователя.
- **P02.** Общий пароль на Caddy ограничивает доступ с интернета. Каждый участник затем входит в приложение своим логином.
- **P03.** Первая выкладка использует новые базы данных. Существующие локальные проекты, файлы и пользователи остаются отдельно.
