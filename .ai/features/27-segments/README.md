# 27. Сегменты — несколько блоков в одном ролике

Человек на сайте делит один топ на сегменты: у каждого свой заголовок, состав, рейтинг и размер.
Топ — источник данных. Ролик по нему монтирует агент через SDK, где документ становится цепочкой
сегментов. Пример — Umineko: интро → «Эпизод 1» с топ-5 → … → «Эпизод 8» → аутро. Заодно
дорабатываем подготовку топа человеком и визуал SDK. Объём решает владелец по списку кандидатов
в [product.md](product.md#кандидаты-в-объём).
