# 27. Сегменты — несколько блоков в одном ролике

Человек делит один турнир на сегменты. У каждого сегмента свои название, состав, мини-турнир,
размер топа и данные для ролика. Сегменты появляются из нескольких архивов, из папок одного
архива или из редактора разбивки. Агент через MCP может сам подготовить такой турнир из файлов,
но места определяет человек. Ролик по турниру монтирует агент через SDK, где документ становится
цепочкой сегментов с новыми возможностями монтажа.

Пример — Umineko: интро → «Эпизод 1» с топ-5 → … → «Эпизод 8» → аутро.

Продукт принят владельцем 2026-11-05. **Автономный режим до вливания** разрешён владельцем 2026-11-05.
Реализованы P01–P09 и принятый объём; дополнительно — плеер по запросу владельца.
[Проверка](verify.md): 913 тестов, production build, типы, живой сайт/MCP/рендер и свежее ревью PASS.
