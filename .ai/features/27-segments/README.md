# 27. Сегменты — несколько блоков в одном ролике

Документ видео становится цепочкой сегментов. У каждого сегмента свой заголовок, источник,
участники или раунды и ранг. Пример — ролик по Umineko: интро → «Эпизод 1» с топ-5 → … →
«Эпизод 8» → аутро. Заодно дорабатываем сценарий топов, объём решает владелец по списку
кандидатов в [product.md](product.md#кандидаты-в-объём).
