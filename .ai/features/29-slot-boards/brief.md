# Бриф

## Слова владельца

> **Доски слотов: тир-листы, Kiss/Marry/Kill** (ваша)
>
> - **Что хотим.** Новый блок `board`. Слоты задаются свободно: текст, цвет, картинка, фон. Режимов два:
>   - «копим»: классический тир-лист, карточки по одной летят в ряды, в конце видна вся доска;
>   - «по раундам»: KMK или «смэш/пас», в каждом раунде N кандидатов, каждый уходит в свой слот.
>   Пресеты: `board.tier`, `board.kmk`, `board.smash-pass`.
> - **Ценность.** Это один из самых ходовых форматов аниме-контента, а заодно шаблон для любых «распредели по категориям». В SDK ложится как ещё один тип сегмента.
>
> Давай постараемся продуктово раскрутить эту фичу, чтобы взять побольше объема, предложи продуктовые идеи которые также можно включить в объем и почему

## Уточнения

- **В:** Как ты представляешь подготовку такого ролика: кто решает, в какой слот попадёт каждая карточка?
  — **О:** «Это задел на будущую интерактивность. Пока нужно реализовать просто эту взоможность на уровне sdk».
- Подтверждённая граница: сейчас SDK. Кто задаёт содержательные решения о раскладке,
  отдельно не определено; вопрос не считается ответом «агент решает за владельца».
- Идеи расширения — предложения агента для обсуждения, не утверждённый объём.

## Трек

`product` — SDK получает новые форматы видео и правила их поведения, видимые в готовом ролике.

## Успех

Из исходного брифа и уточнения владельца:

- SDK описывает доску со свободно оформляемыми слотами и размещением карточек.
- Поддерживаются накопление карточек с итоговой доской и распределение по раундам.
- Есть стартовые пресеты `board.tier`, `board.kmk`, `board.smash-pass`.
- `board` можно использовать как сегмент составного ролика.
- Текущий объём ограничен SDK, а описание доски допускает развитие в сторону интерактивности.

Предложение агента к продуктовой стадии:

- Выбрать дополнительные форматы и общие возможности, которые они требуют, вместо
  добавления только внешне различающихся пресетов.
- Проверять будущую реализацию на законченных примерах: тир-лист, KMK и принятые
  дополнительные форматы. Подробные критерии появятся после выбора объёма.
