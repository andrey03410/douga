## Ревью

Свежий субагент прочитал дифф, рантайм Prisma 7.10.1 и список внешних пакетов Next 14.2.35.
Он подтвердил:
- все процессы открывают тот же файл;
- `@prisma/client` и `better-sqlite3` у Next внешние, middleware Prisma не импортирует;
- порядок удалений в скриптах соблюдает все `Restrict`;
- `@auth/prisma-adapter` нигде не используется.

Замечания:
1. **Средне.** Под `next start` модуль `db.ts` вычисляется в каждом слое сборки, а клиент
   кэшировался в `globalThis` только вне продакшена. Отдельные клиенты дают отдельные
   соединения, и синхронное ожидание блокировки одного стопорит event loop для другого.
   **Исправлено:** клиент кэшируется всегда, `lsof` показал одно соединение.
2. **Низко-средне.** Утверждение «в Prisma 5 было одно соединение» неверно: пул пускал чтения
   рядом с пишущей транзакцией, так что очередь — новое поведение. **Переписано** в `tech.md`,
   комментарии адаптера и `dev-env.md`. Цену записали в «Хвосты»: во время `createTournament`
   запросы процесса ждут. Чинить в этой задаче не стали: для личного сайта ожидание на время
   сохранения архива приемлемо.
3. **Низко.** Запрос через общий клиент внутри транзакции после её отката выполняется сам
   по себе, и запись получается частичной. **Дописано** в грабли `dev-env.md`. Таких вызовов нет.
4. **Низко.** Тест дрейфа клиента больше не ловит изменение только поля-связи: колонки он
   по-прежнему ловит через `<Model>ScalarFieldEnum`. Публичного списка связей в Prisma 7 нет,
   оставлено.
5. Мелочь: `postinstall: prisma generate` упадёт при `npm install --omit=dev`, `prisma` — dev-зависимость.
   Владелец так не ставит, оставлено.

## Попутные находки

- `e2e-setup.mjs` не мог пересоздать `e2e@test.local` на текущей базе, и Prisma тут ни при чём:
  голый `sqlite3` падает так же. Постер сегмента (`Restrict`) не даёт каскаду
  удалить `Art`. **Исправлено** в задаче: `scripts/script-db.mjs` удаляет в порядке `deleteUser`.
- Если пользователь из сессии удалён, `/` и `/projects` переадресуют друг на друга
  бесконечно: `/` смотрит на JWT, `/projects` — на базу. Воспроизведено curl-ом, так же ведёт
  себя и `main`. В «Хвосты».
