## Хвосты

- `createTournament` сохраняет файлы архива внутри транзакции. С Prisma 7 остальные запросы процесса ждут её конца (до 120 с), раньше чтения шли параллельно. Варианты: сохранять файлы до транзакции и переносить их `rename`, или отдельное соединение только для чтения в `sqlite-adapter.ts`.
- Бесконечная переадресация `/` ↔ `/projects`, если пользователь из сессии удалён: `/` проверяет JWT, `/projects` — базу ([verify](verify.md)).
- Prisma 8: вернуться, когда выйдет из кандидатов и SQLite в ней станет стабильным.
