# Live follow-up — явный перенос строки в MotionText

**Verdict: подтверждено. Important — требуется исправление.**

## LT-01: text-words/text-letters теряют визуальный перенос строки

Место: `src/remotion/MotionText.tsx:88–116`, в частности `display: inline-block`
у каждого фрагмента на строке 90. Для words перевод строки остаётся внутри
предыдущего word-фрагмента, для letters — в отдельном inline-block-фрагменте.
В обоих случаях он не переносит следующий sibling в общем потоке. Наличие
`\n` в textContent поэтому не доказывает сохранение отображения текста.

Конкретный валидный вход: `МОУШЕН\nЖИВОЙ ТЕКСТ`, enter text-words либо
text-letters длительностью 21 кадр, кадр 30, window [0,100). Эффект уже
завершён. Вместо двух заданных автором строк получается одна; смысловая
группировка нарушена, длинный результат может дополнительно обрезаться
контейнером. Контракт Task 2 требует сохранения текста и форматов.

Выполнен `node --import tsx` с React renderToStaticMarkup(MotionText), затем
настоящий установленный headless Google Chrome через Puppeteer. У всех
вариантов container width=1800px, font=40px/1.15 Arial, white-space=pre-wrap;
viewport width=2000px. Такой размер исключает случайный автоматический wrap.

контейнера; textContent у всех четырёх вариантов совпадает с исходной строкой.

У words «Ж» начинается на x181.203, у letters на x182.125 вместо x0 на
следующей строке. Probe завершился exit 0. Это собственная живая DOM-проверка,
не вывод по screenshot и не SSR-only проверка. Исходный MP4 и старый diff
повторно не исследовались, suite не запускался.

Направление исправления: сохранить явные line breaks на уровне общего
inline-потока/строк, независимо от анимируемых word/grapheme spans, не теряя
пустые строки, пробелы и Unicode и не нарушая бюджет визуальных фрагментов.
Регрессионная проверка должна измерять геометрию переноса либо реальные пиксели,
а не только конкатенацию фрагментов/textContent. Проверить завершённый вход,
вход/выход и несколько последовательных переводов строк.

этот отчёт. Предыдущая проверка text-lines остаётся верной: дефект относится
