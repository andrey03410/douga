# Моушен-кит для внешнего агента

Черновик руководства: примеры ниже сверяются с фактическим каталогом и compiler
перед завершением задачи. Авторитетные типы — `src/video/motion-types.ts`.

## Быстро собрать сцену

Настройка входит в обычный VideoDocument, новый язык композиции не требуется:

```json
{
  "settings": {
    "motion": {
      "profile": "smooth",
      "intensity": "normal",
      "choreography": "picker-cascade"
    },
    "timer": { "variant": "ring", "warningSec": 3 },
    "backdrop": { "preset": "art-blur", "source": "current-card", "dim": 0.55 }
  }
}
```

Это фрагмент настроек существующего документа, а не полный VideoDocument.
Хореография должна подходить к блоку сцены; каталог показывает совместимость.

## Настроить отдельный элемент

```json
{
  "motion": {
    "enter": "pop",
    "exit": { "name": "slide-up", "duration": { "sec": 0.3 } },
    "loop": "float",
    "emphasis": {
      "name": "glow",
      "at": { "event": "answer.reveal" }
    }
  }
}
```

Пропуск поля сохраняет наследование, явный `null` отключает канал.
Имена `flip-x`, `flip-y` задают ось; `flip` — alias для `flip-y`.
`stagger` задаётся отдельно от эффекта, поэтому каскад сочетается с любым входом.
Длительность/задержка используют обычный Time: `{sec: ...}` или `{frame: ...}`.

## Выбрать характер движения

| Профиль | Назначение |
|---|---|
| smooth | Мягкое спокойное движение |
| snappy | Быстрые читаемые акценты |
| bouncy | Пружинный игровой характер |
| cinematic | Медленное движение камеры и мягкое раскрытие |

Сила `subtle|normal|bold` меняет амплитуду. Для читабельного ролика обычно достаточно
одного входа и одного акцента на элемент; циклы полезны для фонового движения.

## Семантические события

- `scene.start` — начало текущей сцены.
- `card.reveal` — появление карточки.
- `timer.start` — начало времени выбора.
- `answer.reveal` — показ ответа.
- `board.*` — штатные действия доски; можно уточнить cardId/actionId/slotId.

Событие должно существовать в сцене. Ошибка привязки диагностируется; агенту
следует исправить её, а не подбирать абсолютное время наугад.

## Переходы и фоны

Новые `wipe|zoom|push|flash|iris|split|blur|crossfade` задаются обычным
`scene.transition`. Они соединяют начало входящей сцены с удержанным последним
кадром предыдущей, не меняя длительность композиции и звуковые окна.

`art-blur` использует resolved медиа текущей карточки. Пока зритель выбирает,
фон нейтрален или взят из заданного фона раунда. Ответ появляется только вместе
с настоящей фазой ответа. `source:"asset"` требует существующий asset binding.

Процедурные `gradient-flow`, `light-orbs`, `particles`, `vignette` работают без
медиа. Частицы вычисляются из seed и кадра; результат перемотки воспроизводим.

## Проверить результат

Используйте MCP-каталог и готовые примеры, затем validate и timeline. Проверяйте
кадры входа, устойчивого состояния, акцента и перехода. Preview и MP4 используют
один renderer. Подробные доказательства задачи — [verify.md](verify.md).
