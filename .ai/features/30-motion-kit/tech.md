# Технические решения

Решения агента в разрешённом автономном режиме. Продукт: [product.md](product.md).
Свежий builder-check продукта: существенных вопросов нет.

## Исходная система — проверено в коде

- `src/video/schema.ts` — строгие Zod-схемы v1/v2; неизвестные поля отвергаются.
  `types.ts` описывает те же данные, `index.ts` — публичный browser-safe вход.
- `compiler.ts` разворачивает v2 в сегментные v1-компиляции, собирает сцены/аудио,
  проверяет бюджеты. `blocks.ts` создаёт top/picker и временные фазы; доски
  компилирует `board-compiler.ts`, перемещение уже задано ручными keyframes.
- `nodes.ts` создаёт узлы, разворачивает повтор контейнера и разрешает media tokens.
  `settings.ts` наследует вложенные настройки, включая особый случай top.snippet.
- `studio-frame.ts` оценивает keyframes узла по node-local времени, x/y/rotate
  складывает, opacity/scale умножает. Доступны linear/easeIn/easeOut/easeInOut/spring.
- `StudioVideo.tsx` — общий рендерер Studio, watch/offline, PNG/MP4. Сейчас timer
  выводит цифру. Фон — цвет или медиа-узел; style.blur уже существует.
- `transitionAt` делает fade/slide на обоих краях одной сцены. Сцены последовательны;
  новая семантика перехода не должна молча менять старые fade/slide.
- `studio-tools.ts` публикует schema/capabilities/examples и catalog presets;
  `timeline.ts` выдаёт рекомендованные кадры по фазам/ключевым кадрам.

## Решения

### T01. Расширение существующей версионированной модели

- Варианты: произвольный CSS/код; новый движок; аддитивное расширение SDK.
- Рекомендация и **решение агента:** аддитивные optional поля в v1/v2 и IR v1;
  без новых зависимостей/БД. Отсутствующие новые поля не записываются в IR.
  Каталог имеет собственную версию 1. Имена и цвета проходят закрытые схемы.

### T02. Разделение ответственности и контракт

- `motion-catalog.ts` — закрытые имена, metadata и примеры; browser-safe.
- `motion-types.ts` / `motion-schema.ts` — авторские/скомпилированные типы и Zod.
- `motion-compiler.ts` — наследование, хореографии, event anchors, нормализация
  клипов, каскады, фоны, штатные таймеры и VS. Вызывается после custom nodes.
- `motion-frame.ts` — чистая покадровая математика эффектов/переходов/прогресса.
- `MotionBackdrop.tsx` / `MotionWidgets.tsx` / `MotionText.tsx` — визуальные части;
  `StudioVideo` только связывает их с существующим рендерером.
- Точные экспортируемые интерфейсы фиксируются кодом и тестами задачи 1 до задачи 2.

Авторский контракт: `settings.motion` содержит `profile`, `intensity`, каналы
`enter/exit/loop/emphasis`, `stagger` и `choreography`. Узел имеет `motion` с теми же
каналами и локальными настройками. Канал — имя либо объект `{name,duration,delay,
intensity,direction,at}`; `duration/delay` используют существующий `Time`.
`at` — `Time` относительно узла либо `{event,offset?}` относительно события сцены.
События: scene.start, card.reveal, timer.start, answer.reveal и события board.
Отсутствующее поле наследует; `null` отключает канал/хореографию.

`settings.backdrop` задаёт preset, source (`current-card|round|asset`), asset?,
цвета, blur, dim, motion и силу. `settings.timer` задаёт variant, color,
trackColor, strokeWidth, showValue и warningSec. `settings.versus` задаёт variant
и color. Узлы `versus`, `badge` и `progress` имеют типизированные настройки.

`CompiledNode.motion?: CompiledMotion[]`: каждый клип имеет `name`, `channel`,
scene-local `from`, `durationInFrames`, нормализованные `profile/intensity/direction`.
Рендерер не разрешает события и не выбирает рецепт. Текстовые клипы остаются одним
IR-узлом; визуальная разбивка ограничена. `CompiledScene.backdrop` хранит resolved
media layers с окнами, без новых путей вне asset manifest.

### T03. Время, композиция и каскады

- Варианты: сдвиг сцен; сдвиг узлов/аудио; дополнительные визуальные клипы.
- Рекомендация и **решение агента:** визуальные клипы внутри существующих окон.
  Вход/выход ограничиваются доступными кадрами, каскад сжимается при нехватке места.
  Штатные reveal/answer/active окна авторитетны; поздний вход не скрывает весь узел.
  При отсутствии event — диагностируется несовместимость, клип не выдумывает время.
  Stagger контейнера задаёт локальную группу для его дочерних анимированных
  элементов; каналы transform принадлежат самому контейнеру, детям не копируются.
  Неявный глобальный enter применяется к листьям, чтобы не удваивать движение.
  `motion` применяется поверх keyframes отдельным слоем: x/y/rotate складываются,
  opacity/scale умножаются; mask/blur/glow — отдельные свойства.

### T04. Новые переходы

- Варианты: перекрыть таймлайн; удержать предыдущий визуальный кадр.
- Рекомендация и **решение агента:** удержать последний кадр предыдущей сцены
  под входящей. Новые типы анимируют начало входящей сцены; outgoing/incoming
  согласованы. Аудио играет по исходным абсолютным окнам. При показе outgoing
  его собственный переход отключён. Старые none/fade/slide остаются прежними.

### T05. Фоны и детерминизм

- Варианты: отдельное видео; процедурная картинка и resolved медиа.
- Рекомендация и **решение агента:** кадр — чистая функция от frame/fps/seed/IR.
  `Math.random`, wall-clock и CSS keyframe animation не используются. Частицы ≤32,
  текстовые фрагменты ≤500; нет неограниченного умножения DOM по длине видео.
  В decision-фазе current-card не выбирает будущего победителя. Явный asset
  разрешается стандартной проверкой; необязательный отсутствующий арт — нейтральный.

### T06. MCP и галерея

- Варианты: вшить большой каталог в инструкции; короткие summaries с отдельным чтением.
- Рекомендация и **решение агента:** `video_motion_list` с категорией и
  `video_motion_get` по имени; metadata в capabilities, короткий маршрут в instructions,
  полные валидные примеры в examples. Отдельная authenticated страница
  `/studio/motion` использует SDK-компиляцию и настоящий Remotion Player.
  Категории: effect, choreography, transition, backdrop, widget. Превью содержит
  демонстрационные геометрические карточки без зависимости от чужого пула.

### T07. Проверка

- Тесты RED→GREEN: строгие схемы, все имена, приоритеты/отключение, event anchors,
  короткие окна, все fps/форматы, независимость keyframes/board motion, backdrop
  без раннего ответа, соседние переходы, детерминизм перемотки, текст/таймеры.
- Живая проверка: настоящий MCP → create/validate/patch/commit → scoped worker →
  MP4, отдельные кадры переходов/движения/виджетов, декодированный звук.
- Сайт: галерея, Studio/watch и offline HTML с перемоткой и отсутствием JS-ошибок.
- После последних правок строго `npm test` → `npm run build` → `npx tsc --noEmit`.
- Свежий reviewer всей ветки, устранение существенных замечаний до merge.

## Изменяемые зоны

`studio-sdk`, `render`, `mcp`; их карточки обновляются в той же ветке. Dev-env
меняется только если появляется новый воспроизводимый способ проверки.
