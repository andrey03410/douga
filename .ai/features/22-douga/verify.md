## Ревью

Свежий ревьюер смотрел незакоммиченный дифф ветки: код, согласованность `AGENTS.md`,
скиллов и карточек.

- `verify` собирал зоны по `main...HEAD` и не видел незакоммиченное → **исправлено**:
  теперь `git diff --name-only main` плюс неотслеживаемые файлы.
- В `feature` поле `stage` сдвигалось только на `review` и `merged` → **исправлено**:
  каждый коммит стадии сдвигает `stage`.
- Номер задачи и `/feature` не видели невлитые задачи из других веток → **исправлено**:
  номер учитывает ветки `feat/fix/chore`, статус читается через `git show`.
- Порядок тройки расходился (tsc до или после build) → **исправлено**: везде
  test → build → tsc. Перед build проверяется порт 3000 и спрашивается владелец.
- Неясно, нужна ли тройка для правок только в доках → **исправлено**: не нужна,
  достаточно проверить ссылки (`AGENTS.md`, `verify`, `feature` согласованы).
- Сниппет MCP в `Setup.tsx` был без `--silent`: баннер npm ломал JSON-RPC → **исправлено**.
  Ключ сервера в сниппете тоже стал `douga`, проверено на живой `/projects`.
- Фиксированный id градиента в `LogoMark` → **оставлено**: знак рендерится на странице
  один раз, а одинаковые определения градиента не конфликтуют.
