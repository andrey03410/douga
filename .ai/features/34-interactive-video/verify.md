## Ревью

Свежий ревьюер (субагент) по диффу ветки. Исправлено:

- **Существенное: HTTP MCP читал диск сервера через инструменты турниров** (`tournament_create`,
  `tournament_items_add` с `{path}`). Теперь без stdio-сессии `{path}` отклоняется до чтения
  (`LOCAL_MEDIA_DISABLED`). Тест в `api-tokens.integration.test.ts` с настоящей разрешённой папкой:
  без правки турнир создаётся из файла, с правкой — отказ.
- **Гонки публикации**: медленная публикация старой ревизии не откатывает ссылку; задание кадров
  привязывается только к своему снимку; повторная публикация той же ревизии перезапускает пропавшие кадры.
- Лимит 10 токенов — счёт и создание в одной транзакции.
- `canonicalJson`: `undefined` в массиве хэшируется как `null`, как в JSON на проводе.
- `list_pool` по HTTP не отдаёт абсолютные пути сервера.

Оставлено с причиной:

- Пока кадры сцен готовятся, публичные файлы снимка отвечают 404 (не только кадры). asobiba импортирует
  только готовый снимок (409 `SNAPSHOT_NOT_READY`), так что на путь импорта это не влияет.
