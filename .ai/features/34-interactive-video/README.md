# 34. Интерактивные ролики для asobiba

Douga становится движком интерактивных роликов: ядро SDK выносится в пакеты, в документе
появляется интерактивный слой (моменты, выбор карточек, сцены с данными партии), а готовый ролик
публикуется интерактивным снимком. Правила и партию ведёт asobiba. Линейные ролики не меняются.

Парная задача в asobiba — `asobiba/.ai/features/07-video-games/` (ветка `feat/07-video-games`):
мост, видео-контракт игр, сцена партии и Quizor.
