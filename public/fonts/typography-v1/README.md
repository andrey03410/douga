# Шрифты Typography v1

Локальные variable TrueType файлы Google Fonts. Закреплённый снимок
`google/fonts@38411257417e616c5d4daa1b9e91a3dbcebe1c2e`.
Точные исходные URL, SHA-256 и размеры записаны в `sources.json` и
`src/video/font-manifest.ts`. Все семь семейств распространяются по SIL OFL 1.1;
полный текст с copyright каждого семейства лежит в соответствующем `*-OFL.txt`.

Поставляются 400 и 700 normal всех семейств, а также настоящие italic 400/700
Arimo, Rubik и Roboto Mono. Два веса одного начертания используют один variable
файл с осью `wght`; каталог намеренно открывает только два проверенных веса.
Полные японские Noto Sans JP и Noto Serif JP сохраняют покрытие без CDN и загрузки
шрифтов операционной системы. Десять TTF занимают 25 635 784 байта.

Fontkit 2.0.4 читает и проверяет локальные файлы при подготовке измерителя.
В план попадают только реально использованные лица. Сохранённые ревизии отдельно
закрепляют файлы и лицензии по хэшу, а самостоятельный HTML встраивает каждый
использованный файл один раз, в том числе при использовании двух его весов.
